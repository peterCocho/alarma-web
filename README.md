# Alarma Web ⏰

Una aplicación de alarma web desarrollada con tecnologías web modernas.

## Tecnologías

- **HTML5** - Estructura de la página
- **CSS3** - Estilos personalizados
- **JavaScript Vanilla** - Lógica de la aplicación
- **Bootstrap 5** - Framework CSS para diseño responsivo
- **Bootstrap Icons** - Iconos

## Características

- Configuración de hora y minutos
- Selector AM/PM
- Reproducción de sonido de alarma
- Funciones de detener y posponer
- Almacenamiento local para persistencia
- Diseño responsivo con Bootstrap

## Uso

1. Abre `index.html` en un navegador web
2. Ingresa la hora deseada (1-12)
3. Ingresa los minutos (0-59)
4. Selecciona AM o PM
5. Haz clic en "Establecer Alarma"
6. Usa los botones "Detener" o "Posponer" cuando suene la alarma

## Archivos

- `index.html` - Estructura principal
- `alarma.js` - Lógica de JavaScript
- `alarma.css` - Estilos personalizados
- `alarma.mp3` - Sonido de alarma
- `alarm.svg` - Icono de la aplicación
